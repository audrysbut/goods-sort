# Goods Sort — Agent guide

## Project structure

```
src/
  components/    — GameBoard, Shelf, ShelfSlot, SlotCell, Item, LevelComplete
  hooks/         — useGameState (core logic), useDragDrop (HTML5 DnD)
  types/         — ItemType, Item, Shelf, ShelfSlot, SlotDepth, LevelData
  utils/         — levelData (level1), helpers (game logic)
  styles/        — global.css
tests/           — Playwright E2E tests
```

## Commands

```sh
bun install     # Install dependencies
bun run dev     # Vite dev server on :4200
bun run build   # Production build (tsc + vite build)
bun run preview # Preview production build
npx playwright test  # E2E tests (requires running dev server)
```

## Game Mechanics (Current)

- **Structure**: 3 shelves × 3 slots × 3 cells = 27 cells
- **Depth**: Per slot (not per cell) — all 3 cells share depth layers (max 3)
- **Match**: Front layer — all 3 cells in slot show same item → clear that layer
- **Reveal**: Cleared layer removed from all 3 cells → next depth revealed
- **Win**: All shelves empty
- **Level 1**: 3 apples, 3 bananas, 3 oranges pre-matched on Shelf 1; Shelves 2-3 empty for maneuvering

## Key architecture notes

- **Framework**: Preact + TypeScript + Vite (port 4200)
- **Drag & Drop**: Vanilla HTML5 API (no external deps) — `useDragDrop.ts`
- **State**: `useGameState` manages shelves, move history (undo), win detection
- **CSS Modules**: Scoped styles (`.module.css`) alongside components
- **Playwright tests**: `tests/game.spec.ts` (load + drag), `tests/depth-test.spec.ts` (depth mechanic)

## Common gotchas

- `vite.config.ts` sets port 4200 — don't override in `package.json` scripts
- Run `bun run dev` before Playwright tests (tests use `localhost:4200`)
- The `.playwright-mcp/` dir is auto-generated by MCP — safe to ignore/commit
- CSS Modules hash class names in production — tests use role/aria selectors
- Depth is per slot (not per cell) — shared layers across 3 cells
- Only target slot checked for matches after drop (not source slot)
